# PWA Installability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The site becomes installable (Add to Home Screen / standalone
launch) via a static web app manifest and a minimal hand-written service
worker, with a fast-loading repeat-visit shell - no new dependency, no
offline-first ambitions.

**Architecture:** `frontend/public/manifest.webmanifest` (static JSON)
linked from `frontend/index.html`. `frontend/public/sw.js`
(hand-written, unbundled) registered from `frontend/src/main.jsx`, gated
to production only. The service worker's `/api/` passthrough rule is the
only piece of real logic, and gets a standalone tested copy in
`frontend/src/pwa/swUrlMatch.js`.

**Tech Stack:** Vite/React frontend, Vitest + jsdom.

## Global Constraints

- No new npm dependency (`docs/superpowers/specs/2026-09-22-pwa-installability-design.md`).
- Service worker is hand-written, not generated by a build plugin.
- Service worker registration only happens when `import.meta.env.PROD` is
  true - it must never run under `vite dev`/HMR.
- `/api/*` requests are **never** cached or intercepted by the service
  worker - always straight to network, no exceptions.
- Reuse `/api/favicon.png` (the existing favicon asset already wired into
  `index.html`) for manifest icons - no new artwork, no image pipeline.
  See the design doc's "Icon asset decision" for why no static logo file
  exists to reuse instead, and the accepted limitations of this choice.
- `theme_color`/`background_color` = `#6BBF59`, confirmed against
  `frontend/src/index.css`'s current `--brand` value (not assumed from
  any doc).
- Plain hyphens (` - `), never em dashes, in all new code/comments/copy.

- [ ] **Step 4: Write `frontend/public/sw.js`**

```js
// Minimal, hand-written service worker for installability + a faster
// repeat-visit shell. No build plugin, no offline-first ambitions - see
// docs/superpowers/specs/2026-09-22-pwa-installability-design.md.
//
// IMPORTANT: never cache anything under /api/ - admin auth, buyer order
// status, live stock levels, and the whole order lifecycle flow through
// /api/*, and serving a stale cached response here would be a real
// correctness bug (see docs/EDGE_CASE_CHECKLIST.md's Redis-cache-
// invalidation entries for the general shape of this danger class).
// /api/ requests always pass straight through to the network.

const CACHE_VERSION = "v1"
const CACHE_NAME = `app-shell-${CACHE_VERSION}`

// Mirrored in frontend/src/pwa/swUrlMatch.js, which is what's actually
// unit-tested (this file has no test runner access to self/caches/fetch).
// Keep both copies in sync if this rule ever changes.
function isApiRequest(url) {
  return new URL(url).pathname.startsWith("/api/")
}

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches
      .open(CACHE_NAME)
      .then((cache) => cache.add("/"))
      .catch(() => {})
  )
  self.skipWaiting()
})

self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((key) => key !== CACHE_NAME).map((key) => caches.delete(key))))
      .then(() => self.clients.claim())
  )
})

self.addEventListener("fetch", (event) => {
  const { request } = event
  if (request.method !== "GET") return
  if (isApiRequest(request.url)) return // never intercept /api/ - always network, no cache

  event.respondWith(
    caches.match(request).then((cached) => {
      if (cached) return cached
      return fetch(request)
        .then((response) => {
          if (response && response.ok) {
            const copy = response.clone()
            caches.open(CACHE_NAME).then((cache) => cache.put(request, copy))
          }
          return response
        })
        .catch(() => cached)
    })
  )
})
```

- [ ] **Step 5: Register it from `frontend/src/main.jsx`, production-only**

  Append after the existing `ReactDOM.createRoot(...).render(...)` call:

```jsx
// Installable app shell - only in production, so this can never interfere
// with Vite's dev server or hot module reload.
if ("serviceWorker" in navigator && import.meta.env.PROD) {
  window.addEventListener("load", () => {
    navigator.serviceWorker.register("/sw.js").catch(() => {})
  })
}
```
